# Se Liga Aí - Plataforma de Jogos para Crianças Cegas

## Descrição

Este projeto tem como objetivo desenvolver uma plataforma de jogos físicos para promover a aprendizagem de crianças cegas entre seis e dez anos. A plataforma utiliza sistemas embarcados e integra estímulos táteis e auditivos, visando facilitar a adaptação e a participação das crianças no ambiente escolar, dentro da perspectiva da educação inclusiva.

## Objetivo Geral

Contribuir para o processo de ensino e aprendizagem de crianças cegas de forma multidisciplinar, explorando conexões conceituais por meio de jogos interativos.

## Funcionalidades

- Jogos interativos com estímulos táteis e auditivos.
- Diferentes níveis de dificuldade.
- Utilização de mapeamento tátil e descrição auditiva para facilitar a acessibilidade.

## Estrutura do Repositório

Este repositório contém os seguintes recursos:

- **Código-Arduino/**: Código-fonte desenvolvido para os sistemas embarcados.
- **Documentos/**:
  - Documento de requisitos do software.
  - Arquivos de modelagem 3D e do protótipo esquemático
  - Diagramas de modelagem
- **Audios/**: Arquivos e scripts usados para a geração automática de audios.
  - **Scripts/** : script que gera audios a partir de textos
  - **Texto_audios/**:textos utilizados para gerar os audios da plataforma
- **Registro/**: script que faz o registro dos dados do jogo.
